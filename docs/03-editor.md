# Phase 3: Editor

- [x] Parts tray (left): only the parts unlocked for this level, with count left or $ cost
- [x] Drag a part onto the grid (snaps to grid)
- [x] Drag from a node's port to another node to wire them. Right-click or Delete removes.
- [x] Click a node: inspector (stats, trade-off, vendor name, docs link)
- [x] Top bar: level title, budget, error budget bar, Run / Pause / Reset, speed x1 x2 x4
- [x] Forecast strip (bottom): traffic curve + chaos markers, playhead during the run
- [x] Pausing mid-run allows edits. Each edit adds a pager strike (shown).
- [x] Hotkeys: Space run/pause, R reset, Del delete, 1-9 pick part
